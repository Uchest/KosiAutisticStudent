# Autistic Web Designer Portfolio

A clean, responsive beginner portfolio built with:

- HTML
- CSS
- Vanilla JavaScript

## Run locally

Open `index.html` in a browser, or use VS Code Live Server.

## Personalize before publishing

Search `index.html` for:

- `Your Name`
- `hello@example.com`
- `LinkedIn / Your Profile`
- `GitHub / Your Username`

Replace those with your real information.

The contact form is currently a front-end demo. To receive messages, connect it to a form/email service or a backend later.

`myphoto.jpg` is the profile image supplied for this portfolio.
